# Compact hyperbolic Bernstein--Bezier splines

Reference code for **Bernstein--Bezier splines on compact hyperbolic surfaces:
quotient compatibility and spectral approximation**.

The package is intentionally limited to the hyperbolic-quotient paper.  The
spherical, shell, elasticity, conformal-surface and other companion-paper modules
from the larger research code base are not included here.

## Requirements

Python 3.11+ with `numpy`, `scipy`, `sympy`, and `matplotlib`.  The optional 3-D
figure generator also requires `mayavi`, `vtk`, and an offscreen X server such as
`xvfb`.

Run scripts from this directory because the modules use flat imports.

## Core modules

- `hypgeom.py`: Minkowski geometry, stable distance, geodesic interpolation,
  regular polygons and Lorentz side-pairing maps.
- `hypbb.py`: homogeneous Bernstein basis, gradients, Laplace--Beltrami action,
  local mass/stiffness matrices and constant coefficients.
- `hypmesh.py`: Bolza meshes, exact side identification and global assembly.
- `hypc1.py`: `C^r` smoothness rows, including paired edges.
- `prolong.py`: sparse rank-revealing prolongation for the constraint nullspace.
- `klein.py`: general side-pairing patterns and the Klein-quartic 14-gon pairing.
- `hypsurf.py`: opposite-side regular polygons.  In particular, the opposite-side
  14-gon is **not** the Klein quartic; the latter is defined in `klein.py`.
- `nonor3.py`: orientation-reversing pairings for nonorientable quotients.
- `selberg.py`: finite conjugacy-class/length-spectrum utilities and the Gaussian
  Selberg trace-formula terms.

## Reproduce the paper

Basic geometry and algebra checks:

```bash
python test_bolza.py
python test_hypbb.py
```

Bolza eigenvalue table and rates:

```bash
python solve_bolza.py
```

`C^1` biharmonic table:

```bash
python bihar_rr.py
```

Truncated Selberg trace-formula table:

```bash
python selberg_run.py
```

The Selberg driver explicitly removes the detected class at twice the systole
before `geometric_term` generates repetitions.  This keeps the code consistent
with the primitive-class convention used in the manuscript.  The calculation is
a truncation-based consistency check, not a rigorous tail-controlled evaluation
of the trace formula.

Figures are generated by `make_figs.py`; `mayafigs.py` and `compose_figs.py`
produce the optional 3-D panels.

## Conventions

- Hyperboloid: `x.T @ diag(-1,1,1) @ x = -1`, `x[0] > 0`.
- Orientation-preserving groups lie in `SO^+(2,1)`; orientation-reversing side
  pairings are allowed through the full `O^+(2,1)` action.
- Constants are represented exactly only at even homogeneous degree.  Odd degree
  remains convergent but does not contain the exact zero Laplace mode.
- The ordered corner-cycle product is accumulated on the left along the walk.
- Orientation-reversing corner walks require a direction flag.
