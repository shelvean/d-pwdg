Manuscripts by Shelvean Kapita
Department of Mathematics, Texas A&M University

Kapita_Direction_Adaptive_PWDG_Helmholtz.tex / .pdf
    Direction-Adaptive Plane-Wave Discontinuous Galerkin Methods for the
    Helmholtz Equation.  The code, data and reproduction guides in this
    repository accompany this manuscript.  sn-jnl.cls and
    sn-mathphys-num.bst are the LaTeX class and bibliography style it is
    compiled with, and figures/ holds only the figures it references.  The
    transmission section displays the 8- and 32-triangle meshes explicitly;
    the 8-triangle calculations already attain relative L2 error at working
    precision.

Kapita_C0_Bernstein_qT.pdf
    Conforming Bernstein-Bezier Quasi-Trefftz Spaces for Variable-Coefficient
    Elliptic Problems.

Kapita_Bernstein_QuasiTrefftz_Hamilton_Jacobi.pdf
    A High-Order C0 Bernstein Quasi-Trefftz Method for Stationary
    Hamilton-Jacobi Equations.  Its LaTeX source, Python code, data and
    figures are the subproject ../bernstein_qt_hamilton_jacobi/, which
    also carries the two PDFs compiled for the Journal of Scientific
    Computing submission.

The conforming Bernstein-Bezier quasi-Trefftz manuscript is supplied as a
compiled PDF only; its code is not part of this repository.

The conformal spherical splines manuscript (Conformal Spherical Splines for
the Laplace-Beltrami Operator on Genus-Zero Surfaces: Construction,
Algorithm, and Experiments, submitted to the SIAM Journal on Scientific
Computing) is not included here; its Python code and data are the
subproject ../conformal_spherical_splines/.
